HP 12C Gold vs 12C Platinum: what is different, and which one to buy

Short answer

The HP 12C Gold is the classic 12C: RPN only, with up to 99 program lines. The 12C Platinum adds an algebraic (ALG) mode next to RPN and room for up to 400 program lines. In RPN mode the financial keys work the same, so every guide on this site works on both, and both are on the CFA exam's approved list.

In ALG mode the Platinum lets you type ordinary arithmetic the way you would on a basic calculator (3 + 4 =); the financial keys n, i, PV, PMT and FV are used the same way in both modes.

Which one should you buy?

  • 12C Gold: if your course, book or colleagues use RPN, the 12C's classic way of typing. Most HP 12C keystroke guides, including ours, are written for it.
  • 12C Platinum: if you would rather type arithmetic with an = key (ALG), or write long programs.
  • For the financial work itself, either one gives the same answers.
