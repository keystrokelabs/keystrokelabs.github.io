HP 10bII+ setup: P/YR, decimal places, clearing, and what the messages mean

Short answer

RCLorangeP/YRPMT shows P/YR. It survives C ALL, so a P/YR set for one problem stays for the next. orangeDISP= (DISP) and a digit set the decimals.

Works on: HP 10bII+ (and the older 10bII)

P/YR: the setting behind most wrong answers

Payments per year (P/YR) controls TVM, amortization, NPV and IRR/YR. It comes set to 12, and unlike everything else it is kept by C ALL. Textbook problems often assume yearly periods: set 1orangeP/YRPMT for them.

StepKeysDisplay showsWhat it does
1RCLorangeP/YRPMT12.00Show P/YR (here the factory 12).
21orangeP/YRPMT1.00Set it to 1.
3orangeC ALLC0.00C ALL.
4RCLorangeP/YRPMT1.00Still 1: C ALL does not reset P/YR.
512orangeP/YRPMT12.00Back to 12 for monthly problems.

Holding orangeC ALLC (C ALL) down also shows P/YR for a moment on the calculator.

Clearing

KeysWhat it clears
CThe current entry, a pending calculation or a message.
orangeC ALLCC ALL: TVM values, cash flows, statistics and memories, and BEGIN goes back to END. P/YR, decimals and the calculation mode are kept.
blueCC MEMC MEM: the memory registers.

Messages

StepKeysDisplay showsWhat it does
1orangeC ALLC0.00C ALL: clear TVM, cash flows and memory (P/YR is kept).
29000PV250PMT40N40.00Loan and payment both positive.
3I/YRnot FoundNo rate can balance money that only comes in.
4C40.00C clears the message.
5250+/−PMTI/YR6.29Payment negative: the yearly rate.

Here the engine shows not Found; on the calculator the same mistake can show "no Solution". The fix is the same: one of PV, PMT, FV must be negative. With the payment negative, the rate is 6.29% a year.

MessageMeaning
no SolutionNo answer exists for the values entered: usually all money flowing the same way (check the signs).
not FoundThe search for I/YR or IRR/YR did not find an answer; there may be none, or several (cash flows that change sign more than once).
Error P_Yr, Error I_Yr, Error NAn invalid value in that register (for example P/YR of 0).
Error / 0, Error 0 / 0Division by zero.
Oflo, UfloA result too large or too small.
ALL CLEAR, TVM CLR, CFLOW CLRConfirmations that something was cleared.
